# Privacy Policy for NovaMessenger

**Effective Date:** November 2026

NovaMessenger is an open-source desktop messenger application. Your privacy is important to us.

## 1. Data Collection and Usage
- **Account & Messages:** NovaMessenger processes messages and connection metadata strictly to deliver communication between users.
- **No Telemetry or Tracking:** The client application does not include third-party advertising SDKs, analytics trackers, or hidden telemetry.

## 2. Data Sharing
We do not sell, rent, or trade user data or personal information to third parties.

## 3. Open Source Transparency
The full source code of the NovaMessenger client is publicly available in this repository under the MIT License for independent security and privacy verification.

## 4. Contact
For privacy-related questions or requests, please open an issue in the official GitHub repository:
https://github.com/annatkachuk259-bot/Novamesenger-Offical/issues
